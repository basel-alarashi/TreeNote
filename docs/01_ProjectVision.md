# 1. Introduction

TreeNote is a web application that allows users to organize ideas visually using hierarchical concept maps. Instead of writing notes as long paragraphs or simple lists, users create connected topics that form a tree or graph, making information easier to understand, navigate, and remember.

The application combines traditional note-taking with visual thinking by allowing users to build expandable structures similar to mind maps while maintaining a clean and intuitive interface.

Although TreeNote starts as a personal knowledge management tool, its architecture is designed to support future features such as collaboration, templates, AI-assisted mapping, and graph-based relationships.

---

# 2. Vision Statement

To build an intuitive visual knowledge management platform that helps people think, organize, and learn more effectively through interactive concept maps.

---

# 3. Mission

Provide users with a simple yet powerful environment for creating, organizing, and exploring ideas using tree-based structures without overwhelming them with unnecessary complexity.

---

# 4. Problem Statement

Traditional note-taking applications are excellent for writing text but poor at representing relationships between ideas.

Users often struggle with:

- Organizing large collections of notes.
- Understanding hierarchical relationships.
- Brainstorming visually.
- Connecting related concepts.
- Finding information quickly inside large note collections.

TreeNote addresses these issues by representing information as connected topics rather than isolated documents.

---

# 5. Proposed Solution

TreeNote allows users to:

- Create multiple workspaces.
- Build tree-based concept maps.
- Organize topics hierarchically.
- Move topics using drag and drop.
- Search topics instantly.
- Export diagrams.
- Continue working offline.

The result is a visual notebook that encourages structured thinking.
