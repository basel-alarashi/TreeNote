# User Stories

## Authentication

### US-AUTH-001
**As a** guest

**I want** to register an account

**So that** I can create and manage my own workspaces.

---

### US-AUTH-002
As a registered user

I want to sign in

So that I can access my saved data.

---

### US-AUTH-003
As a user

I want to authenticate with Google

So that I can sign in more quickly.

---

## Workspace

### US-WS-001

As a user

I want to create a workspace

So that I can organize different projects separately.

---

### US-WS-002

As a user

I want to rename a workspace

So that its name remains meaningful.

---

### US-WS-003

As a user

I want to delete a workspace

So that I can remove unused projects.

---
